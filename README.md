# Свинг-тренд v2 → Telegram (бесплатно, без подписки TradingView)

Этот бот раз в час сам забирает свечи ETHUSDT.P (OKX) напрямую с биржи,
пересчитывает ту же логику, что и индикатор "Свинг-тренд v2" в TradingView,
и присылает сообщение в Telegram, если появился новый сигнал (вход или выход).
Работает полностью бесплатно на GitHub Actions — твой компьютер для этого
включать не нужно.

## Файлы

- `okx_client.py` — получение исторических свечей с публичного API OKX
- `indicators.py` — базовые индикаторы (EMA, RMA/ATR, RSI, ADX/DMI), как в Pine
- `strategy.py` — сама логика сигналов (копия swing_trend_start.pine)
- `telegram_bot.py` — отправка сообщения в Telegram
- `monitor.py` — главный скрипт, который всё это связывает
- `.github/workflows/monitor.yml` — расписание (раз в час) на GitHub Actions
- `state.json` — создаётся автоматически, хранит "последний обработанный бар"

## Настройка (один раз)

1. Зайди на github.com, создай новый **приватный** репозиторий (например `swing-trend-bot`).
   Приватный — чтобы код и токен были видны только тебе.

2. Загрузи туда все файлы из этой папки (`tv_telegram_bot`), сохранив структуру
   папок как есть (важно: файл `.github/workflows/monitor.yml` должен остаться
   именно в папке `.github/workflows/` — GitHub находит расписания только там).
   Проще всего: на странице репозитория нажми "Add file" → "Upload files" и
   перетащи всё сразу (GitHub сам разложит по папкам, если в самом ZIP/структуре
   папки сохранены).

3. Добавь секреты (защищённые переменные, видны только тебе и работающему
   скрипту, никому больше): в репозитории зайди в
   **Settings → Secrets and variables → Actions → New repository secret**,
   и создай два секрета:
   - `TELEGRAM_BOT_TOKEN` — токен твоего бота от @BotFather
   - `TELEGRAM_CHAT_ID` — твой chat_id (см. как получить в переписке)

4. Зайди во вкладку **Actions** репозитория — GitHub может попросить один раз
   подтвердить, что workflow'ы разрешены ("I understand my workflows, go ahead
   and enable them").

5. Всё, дальше бот сам будет запускаться каждый час. Можно также запустить
   вручную сразу: вкладка Actions → workflow "Свинг-тренд мониторинг ->
   Telegram" → кнопка "Run workflow".

## Важно понимать

- **Первый запуск ничего не пришлёт** — это специально: скрипт просто
  запоминает текущий бар как точку отсчёта, чтобы не завалить тебя
  уведомлениями по всей истории разом. Сигналы начнут приходить со
  СЛЕДУЮЩЕГО закрытого часового бара.
- Логика на Python — это ручной перенос логики из Pine Script. Я проверил её
  на синтетических данных (нет ошибок в расчётах), но не могу подтвердить
  1-в-1 совпадение с TradingView без доступа к интернету из моей текущей
  среды. **Рекомендую первую неделю сверять сигналы бота с тем, что видно на
  графике в TradingView** — если разойдётся, пришли мне пример, поправлю.
- Секреты в GitHub никто, кроме владельца репозитория, не видит и не может
  прочитать даже в публичном логе workflow (GitHub автоматически маскирует их).
